# 规则：语义导演（每一句话该做什么画面）

分镜决定"用哪张卡、几秒"；语义导演决定**这句话在说什么，观众该看到什么**。

**灰盒≠成片**：设计关后必须继续章节/引擎（见 HOUSE「逐章制作」与 `routing/director-routes.json`）。

**默认成熟 = 图二气质**：证据优先卡式包装（非整页 Wiki 平铺、不空框/孤大叉主画面）；四条硬合同见 HOUSE「成熟」。

**文案→包装默认指针链（继承 HOUSE「文案→包装」，不得自创旁路）**：HOUSE 成熟硬合同 + 开场硬门 → `routing/compositions.json` 十构图（`hero-object`/`map-table`/`count-field`/`figure-card`/`sequence-line`/`evidence-card`/`split-compare`/`globe-route`/`queue`/`title-footage`；**证据拍默认 `evidence-card`**）→ 开场只认 `kit.status==="ready"` 的 `lineup-row`/`copy-to-repeat`/`table-grows` 或章节 `mapPlane`/`subject`/`orbit`（空壳 `array-build`/`stagger-reveal`/`light-3d` 不得当允许开场）→ 金样 `projects/paperclip-138-open/chapters/B01.mjs` → 禁单 `lessons.json`+`tells.json` → 导演路由表 `routing/director-routes.json`（开场/证据/数字/地图/对比 → ready 装置/gold）。

## 第一步：处理阶梯（先选怎么处理，再想怎么动）

每一句先从上往下问，**停在第一个做得到的台阶**，写进分镜的 `treatment`：

| 台阶 | `treatment` | 什么时候用 | 画面 |
|---|---|---|---|
| 1 证据 | `evidence` | 这句话里有能找到真实画面的东西：人、公司、产品、地点、新闻事件、行情、网页、论文、录屏 | 真实素材本身（照片、视频、截图、Logo、行情表），上面只压短字；新闻页用读报（推近到那一句 + 高亮，不压字） |
| 2 主讲人 + 贴签 | `presenter-tags` | 作者在下判断、强调、反问，关键词值得钉在屏幕上 | 主讲人画面 + 两三张纸贴签，按口播逐张出 |
| 3 数据 | `data` | 有两个以上的数字可比，或一个数字是这一段的钩子 | 纸面数据拼贴、图表、行情表；数字只用原文的，或者项目里已存档的原始报道里的 |
| 4 结构图 | `diagram` | 讲机制、步骤、因果（"抠出 20 个单元专门搬数据"） | 让关系与变化看清：平面、2.5D 或真实 mesh 按表达需要选，空间形状有解释作用才用 3D |
| 5 标题 | `title` | 时间、章节、一个概括词 | 按语义设计字组和画面；可配真实照片或视频，遵守 HOUSE 禁用金属 3D 字 |
| 6 留白 | `presenter` | 作者自己的口气、情绪、过渡；也给观众喘口气 | 纯主讲人，或一段空镜 |
| 7 隐喻 | `metaphor` | **只在**上面都做不到、又必须把一个关系讲清楚时 | 见下面的六步 |

要点：
- **事实句先给证据。** 说到英伟达，就给英伟达（新闻画面、行情、Logo）；说到华尔街，就给华尔街；说到白宫，就给白宫。真实素材走素材步骤，人物、Logo、截图都可以用，**不能用的只是"生成的假人、假截图、假 Logo"**。
- 证据写进 `evidence`：每一条是一样要找的真实画面（`kind` 人物/公司/产品/事件/地点/空镜/作者软件，`what` 画面里是什么，`entity` 名字，`queryEn` 英文检索词）。
- 一句话里点了好几样东西（"不是华尔街的巨鳄，不是哪个国家的政府"），就在这一拍里**快切**：`scenes` 每一样一刀，0.5–1.5 秒一刀。快切是蒙太奇，不是一镜摆满。
- 事实句没有用证据时写 `noEvidence`：为什么找不到或不该用。
- 主讲人是骨架：留白镜头和贴签镜头加起来大约占三分之一，均匀地插在证据之间。
- 3D、几何、LED/CRT 介质按语义和全片方向选，既可以承担主体，也可以不用；不为凑手法加装饰。具体设备质感可成为整段视觉语言，但须适合内容并保持可读。

制作前读 `work/recipe-board-v1/SEMANTIC-VISUAL-DIRECTION.md`：先确定观众问题和载体，再选择可用手法；静帧先做好主次、真实素材、排版和全片协调，不用重复占位冒充设计完成。

## 隐喻和结构图镜头：六步

只有 `treatment` 是 `metaphor` 或 `diagram` 时才走这六步。好的隐喻是让这句话的意思**在画面上发生一次**：说"蒸发"，东西就蒸发；说"整个板块"，镜头就拉开看到一整片。


1. **语义核心**：这句话的骨架是什么关系？从下表选一个（可以两个），不要停在关键词上。

| 语义关系 | 例句 | 画面上要发生的事 |
|---|---|---|
| 数量 / 规模 | "蒸发了将近 6000 亿" | 一个有体量的东西，体量本身被看见、被改变 |
| 变化 / 突变 | "一天之内""突然宣布" | 同一个物体从状态 A 变成状态 B，变化点要有冲击 |
| 比较 / 纪录 | "历史上最大的一笔" | 并排或纵深排开，主角最突出；示意的要标示意 |
| 部分 / 整体 | "整个板块加起来" | 镜头拉开：一个变成一片，再合成一个总量 |
| 排除 / 反转 | "不是…不是…是…" | 候选依次出现、熄灭；剩下的那个亮起 |
| 未知 → 揭晓 | "没人听过名字的…它叫 X" | 先给空白（空名牌、黑屏、问号），再让答案一点点出现 |
| 以小搏大 / 反差 | "一群人一个周末，让整个硅谷失眠" | 同一画面里一小一大，小的触发大的 |
| 因果 / 传导 | "所以""导致" | 一条可见的路径：从因流向果 |
| 时间 / 尺度 | "过阵子也就忘了""十年" | 时间轴拉长或镜头拉远，主角在新尺度里变小 |
| 过程 / 机制 | "抠出 20 个单元专门搬数据" | 结构图里真的有部件被拿出来、重新连起来 |
| 引用 / 证据 | "论文里写的原话是" | 真实证据（截图、原文）作为一块屏或一张纸进入空间 |
| 情绪 / 态度 | "离谱""吓人" | 用光、节奏、尺度表达，不用表情包 |

2. **联想**：这个关系在现实里像什么？至少想 3 个，写下来，划掉最俗的那个（股市 = 红绿 K 线、AI = 发光大脑、速度 = 光线隧道……）。
   - 从**动词**联想（蒸发、砍掉、补回来、失眠、忘了），动词就是动画。
   - 从**物件和场景**联想（行情墙、名牌、按钮、夜里的楼、时间的长河）。
   - 中文口语里的比喻常常直接能用："一拳打碎""卡脖子""炸出满血"。
3. **视觉隐喻**：选一个，写成一句"什么东西 + 发生什么变化"。必须满足：
   - 换掉这句话就不成立（不是通用装饰）；
   - 不替代事实：事实性的东西（数字、人、公司、新闻）用真实素材或代码写的原文，隐喻只承载关系；示意性的画面标"示意"。
4. **运动**：这个变化怎么动——速度、重量、曲线。蒸发是慢慢往上散、越来越淡；崩塌是先停顿再一下掉下去；揭晓是逐点亮起。动画参数按 `CAMERA.md` 和动效 tokens。
5. **镜头**：观众从哪个位置看这个变化最有力？变化点要不要冲击推近？要不要拉开看全貌？一镜一个镜头运动，停留时稳。**先定镜头戏再铺字**：每镜必须有镜内运动 + 字进时机。**开场只认已接线**：`lineup-row` / `copy-to-repeat` / `table-grows`，或章节 mapPlane/subject/orbit；禁止未接线空壳与同图×N CSS rise；禁止静帧照片海报 + 大字硬切当开场主戏——不要只靠横移扫一张全幅图。字晚进；进近景用 push/whip。`push` 必须有真 from/to 景别（缩放）变化。下游 agent 不得绕过 HOUSE 自创静图开场。
6. **接续**：和上一镜怎么接？最好是**同一个物体变下去**（走势带变成一片走势带，再变成长河），其次是动作或形状匹配，最后才是硬切。全片要有一个贯穿的主体（简报里的母题）。

## 写法（每一镜的 `idea`）

```
语义：部分/整体 + 数量
联想：一根带子变成一片带子；一面墙的行情一起翻红；很多水滴汇成一片云（划掉：饼图）
隐喻：英伟达那根发光带子退后，旁边一根根带子亮起来，全部同时坠落，蒸发的粒子汇成一大团
运动：带子依次亮起（错开 0.06 s），坠落同时发生；粒子慢慢往上汇聚
镜头：从近景升起、拉远 0.6 s（quart.inOut），停住
接续：同一根带子（上一镜的主角）
```

## 底线

- 先理解再联想；理解不了就回到原文，不要拿关键词配图。
- 每一镜只演一件事；一镜里的隐喻不超过一个。
- 隐喻不能歪曲事实：示意画面标"示意"，不给真实公司编数字，不用生成的图冒充真人和新闻。
- 隐喻不能替代证据：事实句有真实画面可给时，不用隐喻。
- 不用陈词滥调：发光大脑、机器人、红绿 K 线截图、光线隧道表示"快"、地球仪表示"全球"。
