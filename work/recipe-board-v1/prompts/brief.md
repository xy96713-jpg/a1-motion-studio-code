# 规则：全片简报（brief）

你是这部片子的导演。读完整篇文章和已经拆好的拍点（plan），先想清楚**整部片怎么讲、怎么看**，再写简报。
简报不出画面，它决定后面每一镜怎么设计：章节、节奏、母题、风格、高光、留白、前后呼应。

输入在任务文件 `tasks/brief.task.json` 里：文章全文、每拍（id、意图、屏幕大字、原文）、主题、可用卡片、节奏规则。
答案写到 `tasks/brief.answer.json`，格式见 `routing/brief.schema.json`。系统会检查，不过就退回并写明原因（`tasks/brief.check.json`）。

## 怎么想

1. **一句话影片**（`film.logline`）：这部片讲什么，30 字以内，用原文的事实。
   **推动全片的问题**（`film.question`）：观众一路想知道答案的那个问题。好的科普片几乎都由一个问题推着走。
   **感受**（`film.feeling`）和**带走什么**（`film.takeaway`）：写给自己看的，决定语气。
2. **章节**（`chapters`）：按叙事功能切，不按话题切。
   - 角色只能是：`hook`（开场钩子）、`setup`（交代）、`story`（讲经历 / 事件经过）、`rise`（推进）、`turn`（反转）、`climax`（高潮）、`resolution`（收束）、`coda`（尾声）。第一章必须是 `hook`，全片至少一个 `climax`。
   - 章节首尾相接、按顺序覆盖所有拍，不跳、不重叠。60–100 拍的文章通常 5–8 章。
   - 每章写 `tension`（0–10 的紧张度）。整片读下来应该是一条有起伏的曲线：钩子高、交代回落、逐步推高、高潮最高、尾声回落。不要一路平。
   - `pace`：`slow` / `steady` / `fast`，对应镜头平均长度和切换频率。
   - 角色决定这一章的节奏目标（`routing/rhythm-by-role.json`，任务里的 `rhythm.roles`）：平均一刀几秒、主讲人占比、证据占比、最长多久不见人。分镜会按它检查，所以角色要按这一章真正的叙事功能选：抛问题、交代人物是 `setup`，按时间讲一个人的经历、一件事的经过（哪年、在哪、做了什么）是 `story`，讲原因是 `rise`，讲机制的高潮是 `climax`，讲后果是 `turn`，讲意义是 `resolution`。
   - `accent`：这一章的强调色（`#RRGGBB`），从主题色板里取或在它附近，全片不超过 3 个。
   - `look`：这一章的画面基调，一句话（例如"暗场、行情屏、数字压迫感"）。
3. **母题**（`motif`）：一个在全片反复出现的视觉元素，让观众知道"讲到哪了"、让片子有整体感。
   - 例子：一张不断被填满的流程图；一条一直延伸的时间线；同一个按钮、同一块屏幕、同一个数字。
   - 至少出现 3 次，分布在不同章节，每次写清楚它的状态（第一次是空的、第二次填了一半……）。
   - 必须能用现有手段做出来：代码图形、卡片、几何体或真实素材。
   - `broll`：再点名**一种真实空镜**做全片的空镜母题（同一种场景或物件，比如同一种城市夜景、同一张办公桌），写它是什么（`what`）、英文检索词（`queryEn`）、什么句子切到它（`lines`：情绪句、夸张句、讲到这个主题时）。分镜遇到这些句子就切回它，每次同样拍。
4. **节奏**（`rhythm`）：帧率 30；`bpm` 决定切镜的网格（没有音乐也按这个网格切）。快节奏 110–128，叙事 90–100，沉思 70–84。
   - `breathingBeats`：留白的拍（只放主讲人或空镜），约占全片的 1/5 到 1/4，分散在章节之间和高潮前后。留白是"不加新信息"，不是"画面不动"：原片每次停住只有 1 秒左右（九成在 3.4 秒以内），而且是在一直在动的画面里停。所以超过 3.5 秒的留白拍要让画面变一次，三选一：压暗、拉远、被信号抹掉。原片的例子："如果他没出现过"回到身高墙，剪影被雪花抹掉；"这只是理想情况"让同一张家谱缩小、变暗。plan 里意图是 `presenter-plain`、`atmosphere` 的拍通常就是。点了具体的人、公司、地点、事件的拍不做留白：那里该给证据（见 `visual-director.md` 的处理阶梯）。
5. **形式**：任务里的 `format` 是 `voiceover`（没有主讲人画面，全片是画外音配包装）时，不要安排主讲人拍，也不要写"主讲人主导"：留白交给空镜、标题和停住的图；讲原理的章节用连续图解（一张图一直变），这是这类片子的主体。
6. **风格**（`style`）：
   - 任务里有 `filmStyle`（项目定的整片风格，`routing/styles.json`）时：`palette` 照它的 `palette`（底、字、强调三色一字不改），`world.base` 照它的 `ground`（light 写 paper，dark 写 dark），`sixCell`、`typography`、`world` 的其余部分在这套风格里写怎么用；不另选风格（风格只在 `project.json` 定一次，用户在「定样子」关看）。
   - `theme`：用项目的主题；
   - `sixCell`：六格简报——介质（画面像什么：纸面、屏幕、档案…）、出字（字怎么出现）、标注（怎么指东西）、色彩（每章 / 每镜怎么换色）、转场（默认硬切，什么时候用别的）、运动（镜头怎么动，遵守 `CAMERA.md`：默认锁定、一镜一个镜头主人）；
   - `palette`：底色、字色、强调色（hex）；`typography`：一句话。
   - 任务里有 `reference`（对标的参考片，它的样子）时，`world`、`palette`、`typography` 和 `sixCell` 都照它定，不要沿用项目原来的主题。
   - `world`：这部片自己的世界，系统按它生成全片主题，开场标题到最后一张图表都用这一套。`base` 底：`dark`（暗场）或 `paper`（纸面）；`display` 标题字：`sans-heavy`（粗黑体）、`serif-heavy`（粗宋）、`condensed`（窄体）、`pixel`（像素）、`mono`（等宽）；`texture` 纹理（可多选）：`grain` 颗粒、`vignette` 暗角、`vignette-light` 轻暗角、`dots` 网点、`rulers` 参考线、`chromatic` 色差；`medium` 介质：`tube`（老显像管）、`none`（干净）、`film`。按题材选：刑侦、档案、科技一般用暗场、粗黑体、网点加颗粒；人文、历史一般用纸面、粗宋。颜色取 `palette`。
   - `stage`（plan 里有 `teardown` 或 `scene` 拍时必填，没有就写 `null`）：3D 镜头怎么放进这部片的世界。`look` 一句话（例如"拆解用冷灰纸面线稿，和卡片同一张纸；夜景用胶片颗粒，偏青黑"）；`subject` 拆解的底：`dark` / `paper` / `red` / `ink`，跟底色走；`sceneMedium` 意境场景的介质：`film`（夜景的重颗粒）、`filmday`（白天的轻颗粒）等；写了就全片统一用它，写 `null` 时每个场景按自己的亮度选。颜色取 `palette`，3D 镜头和卡片用同一套底色、字色、强调色。任务里的 `stage` 列出现在能拆的东西和能用的场景，库里没有的会先显示 TODO。
7. **高光**（`heroMoments`）：全片最该被记住的 3 到 8 个瞬间（不超过总拍数的 15%）。写为什么是它、打算怎么处理（例如"数字从 0 滚到 6000 亿，冲击推近，一帧闪白"）。高光以外的镜头要克制。
8. **介质镜头**（`mediumShots`）：如果主题有介质（LED、CRT、网点），只给少数"屏幕感"的瞬间用（标题字、章节开头、数字揭晓），不超过总拍数的 15%。要读的正文、表格、聊天、主讲人、实拍都不用。主题没有介质就留空。
9. **前后呼应**（`callbacks`）：前面埋下、后面回收的东西（例如开头的"6000 亿"，结尾说"反倒没那么要紧了"）。回收的镜头要在画面上真的呼应前面那一镜。
10. **禁用**（`banned`）：这部片绝对不要出现的东西，至少 5 条。从默认禁用表开始，再加这篇特有的：
   紫蓝渐变、霓虹光晕、装饰粒子、所有元素同时淡入、每个元素都淡入上滑、居中堆字、读的时候字还在动、镜头持续晃动、满屏故障效果。
11. **风险**（`risks`）：事实上要小心的地方（ASR 听错的专名、需要核实的数字、不能生成的真人照片）。

如果任务里有 `previousAnswer` 和 `checkErrors`：在上一版上改掉这些错误，其余保持不变。

## 底线

- 只用原文里的事实；数字、人名、引用都来自文章，不编造、不改写。（分镜阶段可以给事实句找原始报道：用户确认、截图存档后，报道里的精确数字也可以上屏。）
- 每个拍 id 必须来自 plan。
- 简报讲"怎么拍"，不写具体每一镜的卡片和动作（那是分镜的事），但要给分镜足够的方向。
