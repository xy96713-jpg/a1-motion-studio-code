# 细拆对标片的一段（breakdown）

你拿到的是对标原片一段的密集帧（每秒 2 帧、带时间戳，每张 20 格）和这段的字幕时间（`input.subtitles`），以及手法库（`input.devices`）。任务是把这段**拆到能照着做的程度**，不是描述"用了什么"。

按我们这部片的拍（`input.ourBeats`，原片讲同一句话的位置）一拍一条，写：

- `elements`：画面上每一个元素：`what`（是什么、什么形态、在哪个位置）、`in`（第几秒出现，原片时间）、`out`（第几秒退场，没退写 null）、`word`（它落在字幕里的哪个字上）。新元素出现、变形、移动都算一条。
- `carryOver`：这一拍结束时什么留到下一拍（物件、版式、背景字、颜色）；什么都不留时写清为什么（硬切、换章）。
- `devices`：这一拍用的手法，从手法库里选 id；库里没有的新手法，先加进 `routing/devices.json`（写清 what / when / how / from）再引用。
- `idea`：一句话说清这一拍为什么用这个画面讲这句话（比喻、呼应、对比、强调）。

整段再写一条 `carrier`：这一段跟着走的那个物件和它的变化链（例：血样管 → DNA 卡 → 家谱里的方块 → 排查队列里的人）。没有就写"无"并说明。

看帧时特别注意：
1. 同一个东西在相邻格里是不是变了形、换了位置（这就是贯穿物件）。
2. 开头的画面在结尾有没有回来（首尾呼应）。
3. 标题出现后去哪了（变底纹、变角标）。
4. 结论句前后有没有突然的尺度、颜色变化（强调）。
5. 换场景时什么没动。
6. 每个元素出现的时刻对的是哪个字。

输出：`{ "contract": "A1ReferenceBreakdown/v1", "film", "section", "ourBeats": [...], "carrier", "beats": [{ "beat", "from", "to", "elements": [{ "what", "in", "out", "word" }], "carryOver", "devices": [...], "idea" }] }`。系统会检查每个元素有 in 和 word、每拍有 carryOver、devices 都在库里、每拍有 idea。
