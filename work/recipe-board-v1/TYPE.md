# 排版圣经（现行）

用户 2026-10-28：「字体设计的不好 你没什么排版规则和圣经吗 很多位置都怪怪的」。之前只有约束（家里的字、最小字号、不叠字、不贴边、字随声出），没有设计系统：每拍各挑字号、各找空位，大小字上下颠倒，数字一会儿大一会儿小，整片读起来是散的。这一页是全片排字的规矩；数值在 `routing/type-bible.json`，代码按它量（`typebible.mjs`），灰盒和每一章都量。

## 1. 网格

- 1920×1080，左右边距 120，上边距 96；字不进 935 以下的字幕带。
- 12 栏，栏宽 118，栏间 24。左对齐的字，左边缘落在某一栏的左线上；右对齐的字，右边缘落在某一栏的右线上；居中的字，中线在画面中线上。允差 24 px（光学对齐：字形的墨迹在字框里有空隙）。

## 2. 字号阶梯（只有五档，允差 6%）

| 角色 | 字号 | 用在 |
|---|---|---|
| hero | 300 | 重头拍的大字，一拍一个 |
| figure | 200 | 关键数字（数字加单位），全片同一档；重头拍可用 hero |
| title | 128 | 一拍的主句、事件名 |
| sub | 64 | 配在大字下面的小字 |
| caption | 48 | 日期、地点、说明标签 |

同一种角色全片同一档。不另造字号。

## 3. 大小字组合

- 大字配小字是一个整体，**左边缘对齐**（只有纯字卡居中，中线对齐），对齐到 6 px 以内；两行一起钉住、一起微移，不各走各的。
- **间距只有一个**：两行之间看得见的空隙（上一行笔画的底到下一行笔画的顶）是大字字号的 0.15 倍，误差 ±0.03（2026-10-28：间隔什么的是不是也怪 应该可以更规范的）。按笔画量，不按字号盒子量：盒子量时，没下伸笔画的数字、上面空着的「10%」看着一松一紧。
- **数字和中文一样高**：一行里有数字又有中文（400米、367艘、2021年3月），数字画到中文的高度，顶和底都齐，误差 5%（2026-10-28：数字和文字为什么对齐不了）。
- 上下按台词的顺序：台词先说小字的（引子，如「每堵一天」→「九十億美元」），小字在上；后说的（补充，如「10%」→「全世界的貿易」），小字在下。

## 4. 落位

几个固定的位置，按构图选，选它要有理由：

- 标题块：左边 1–5 栏，上三分之一；
- 数字块：右边 8–12 栏或左边 1–5 栏，中间高度；
- 日期、地点：左上角，上边距处；
- 说明：左下，字幕带上方；
- 重头大字：居中。

字不漂在空处；同一部片里同一种角色尽量站同一种位置。

## 5. 和东西的关系

- 贴在东西上的标签（地名、船名）可以钉在物体上随镜头走，字号也要在阶梯里，不小于 caption。
- 关键数字和标题放在屏幕网格上，不钉在会动的物体上（钉着走就落不到网格上，这是苏伊士字乱的根源）。
- 标签说的是哪个东西，就站在那个东西空着的一侧，对齐它的边缘；离得远就用引线。

## 6. 点缀色

一帧一处：关键的那个数字或词。标题、说明、标签都用这一拍配色的字色。

## 量尺（`typebible.mjs`，量每一拍停稳后的那一帧的屏幕字）

- 字号不在阶梯里；
- 屏幕字不落在网格线上、出了边距或进了字幕带；
- 大小字：小字在大字上面、边缘不齐、间距不对；
- 不止停稳的一帧：这些规则在一拍的每一刻（每 0.2 秒）都量，错 0.8 秒就算这一拍错；
- 全片：关键数字不是同一档；
- 钉在物体上的标签小于 caption。
- 一帧的字不是一个字组（手排的显示字）、字组不在一条轴上、3D 场景里的字和屏幕字配成一组；
- 层级超过三级、相邻两级不到 1.5 倍、最大一档不止一个、两组字挨得像一组；
- 一行字停留的时间读不完（每秒 9 字加 0.3 秒）。

## 7. 成熟规范（2026-10-28，用户：上网找最好的设计规范 字体的 排版的 嵌入进去 要特别成熟 才行）

字的设计用一套方法，不用一条条补丁：**一帧的字是一个设计好的字组，不是一行行摆**。每条规范都有出处，都落成零件和量尺。

| 规范 | 我们的做法 | 出处 |
|---|---|---|
| 字幕安全区：画面四边各留 5%（字幕安全 90%） | 页边 120/120/96，更严 | EBU R95；SMPTE ST 2046-1；Netflix 交付规范 |
| 网格：版面由栏和模块组成，字落在栏线上 | 12 栏网格（§1） | Müller-Brockmann《Grid Systems in Graphic Design》 |
| 字号成比例阶梯，不随手取 | 五档（§2），相邻档 ≥1.33× | Bringhurst；Tim Brown「modular scale」 |
| 层级：一个先读的，最多三级（标题、副题、说明），两级之间要拉得开 | 一帧最多三档；同框两档至少差 1.5×；最大一档只有一个（一个字组） | School of Motion「tiny typography decisions」；Pangram Pangram「typographic hierarchy」 |
| 接近：属于一起的靠近，不属于的分开 | 组内笔画间距 0.15×大字；组与组至少 0.5×大字 | 格式塔接近原则 |
| 对齐：一个字组一条轴，以左对齐为主，居中少用 | 字组按笔画对到同一条轴（左、中、右），误差 6 px | Butterick《Practical Typography》 |
| 光学对齐：按笔画不按字框 | 零件按每行首尾字的笔画放笔；混排行量首字和末字 | 光学边距对齐（optical margin alignment） |
| 中西文混排：数字和汉字之间不超过 1/4 字宽；数字用半角 | 数字和中文同高同底、紧排（morph.js） | W3C《中文排版需求》clreq；Netflix 中文字幕规范 |
| 大标题可以收紧或拉开字距（詰め組、均等割り） | 拉宽单词零件 spreadWord（首字笔画落左线、末字落右线） | W3C《日文排版需求》jlreq |
| 读速：中文字幕每秒最多 9 个字 | 每行字停留 ≥ 字数÷9 + 0.3 秒 | Netflix 中文字幕规范 |
| 字体少：一个家族的不同字重分层级，最多两款 | 家里的字按角色固定（§HOUSE），镜头不自己挑 | PremiumBeat「motion title design」 |
| 先删字再排字；字离开画面焦点和画边 | 一帧最多三行要读；字随声出 | School of Motion |

### 零件（`kit2.js`，章节里用 `type.flat.*`）

- `typeBlock(g, { lines: [{ text, size, role, color, a }], axis, x, y, from })`：一帧的字作为一个字组，按笔画对到一条轴，行间统一间距。日期/出处行显式 `role:'caption'`，保持 caption 档和既有字体：纯 Latin 出处同行的年份保持原生字母墨高；含 CJK 的混排 caption 整行以中文墨高为目标，Latin/日期同高同底，不因中点分 run 改变目标。角色和整行语义同时用于测量和绘制，结束或异常后恢复。关键数字（figure/未指定角色的既有显示字）仍走原等高规则。
- `spreadWord(g, { text, x0, x1, y, size, k })`：一个词拉开铺满一段宽度，比如开篇的「一　艘　船」。
- `pair` / `peakType` / `evidenceCard` / `stackType`：都是字组，排法同上。

显示字（title 一档以上）不经这些零件直接画，检查判错。

### 你认可过的设计不被审片改掉

你看过、认可的版式（比如开篇拉宽的三个字）是锁住的：盲审和仲裁只报硬错（叠字、出画、看不清、事实错），提出改它的构图或字的意见作废；要改，先拿前后对比给你看，你说了算（教训 L123）。

## 8. 屏幕上的字还要多想一步（2026-10-28 体检，取自通用动效排版技能 hyperframes-creative 的 typography.md，按我们的家里字体改）

- **时间就是层级**：先出现的最先被读。一拍里先出主角，或者先出它的引子；说明和标签后出。字随台词出现，台词顺序就是阅读顺序。
- **能读完再走**：一行字停留的时间里，要能读两遍。线上按每秒 9 字加 0.3 秒量（`readTimeErrors`）。字多就删字、放大，不缩短停留。
- **大字收紧**：大字（title 一档以上）的字距按设计收紧（日文排版的「詰め組」）。要拉开也是整词拉开（`spreadWord`），不在一行里松松散散。字形的胖瘦只由 `shapedFont` 按风格做，模块不自己拉伸。
- **深底上的浅字**：浅字压深底，看起来更重、更挤。小字（sub、caption 两档）在深底上不用比 caption 更小的字号，和上下的字至少隔一个标准间距；点缀色的字在深底上要够亮。对比度由画面检查量（`framecheck` 的 contrast）。
- **跳动的数字等宽**：会滚动、会数上去的数字用 `counter` 零件。它按数字的笔画宽度给每一位固定一格，数字跳动时位置不抖。
- **一个字体家族分层级**：层级靠字号和颜色拉开，不靠换字体。家里的字按角色固定（HOUSE.md），镜头不自己挑。
- **标签贴着它的东西**：用 `labelBy(g, text, thing)`，放在那个东西空着的一侧，间距是标签字号的一半。离它超过字号的 1.5 倍就判错。
